# 项目说明

诚然，这个游戏美术是 NovelAI 画的，音乐是 Suno 编的，程序是 Phaser 写的，但是本单机版是不借助任何IDE，用记事本一个字一个字打出来的100%纯正古法编程。

并且为了尊重知识产权，本项目不含任何游戏资源文件，你必须自行获取游戏资源，方法如下：

## 运行方法

1. 告诉你的 Agent，从 `https://tcd3-master-front.tencross.site` 下载 `resource.txt` 里所列出的所有文件，并按相对路径存放到当前子目录。
2. 在当前目录启动 HTTP Server，并用浏览器打开 `index.html`。



Although the art of this game was generated with NovelAI, the music was composed by Suno, and the code was built with Phaser, this standalone version is 100% pure artisanal old-school coding, typed character by character in Notepad without stooping to use any IDE.

Furthermore, to respect intellectual property, this project contains zero game asset files. You must obtain the game assets yourself by following the instructions below:

## How to Run

1. Tell your agent to download all the files listed in `resource.txt` from `https://tcd3-master-front.tencross.site` and save them into the current subdirectories according to their relative paths.
2. Start an HTTP server in the current directory and open `index.html` in your browser.
